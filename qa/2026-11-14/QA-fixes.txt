[x] BUG-01 프리셋과 편집 범위 불일치 수정
- 최대속도 범위: km/h 10~400, mph 5~250. 과속 기준: km/h 5~400, mph 5~250.
- 기존 저장값이 범위 밖이어도 편집창 진입만으로 잘라내지 않음.
- 변경 없이 확인 시 단위 환산 이전 원본 km/h 값을 유지.
- 도보 20km/h → 편집창 20 확인. mph에서 12mph 표시 → 그대로 확인 → km/h 복귀 시 20 유지.
- 고속 프리셋 과속 기준 300km/h → 편집창 300 확인.
- 부동소수점 오차 때문에 345가 344로 표시되던 부분도 반올림 처리. 최종 APK에서 345 확인.
- 증거: fix-07, fix-33~35, fix-39.

[x] BUG-02 거리 단위 부분 적용 수정

- km/h + mi: 요약 9.7mi, 목록 0.0mi, 최장거리 카드 및 상세 8.2mi 확인.

[x] BUG-04 GPS OFF 후 이전 값 잔류 수정
- 위치 서비스 OFF 이벤트 시 속도 0, 정확도 없음, 비활성 상태를 방출하고 위치·필터 기준 초기화.
- 유효 위치가 5초간 갱신되지 않으면 비활성화. 1초 감시 주기이며 마지막 위치 나이는 단조 시계 기준.
- 만료된 캐시 위치와 역순 위치 거부. 신호 상실은 주행 샘플로 적재하지 않음(timestamp 0).
- 실제 폰: 수신 ±3m → 위치 OFF(location_mode=0) → 2초 대기 캡처에서 빨간 GPS / -- 확인.
- 위치 ON → 앱 재시작 없이 7초 대기 캡처에서 ±9m 수신 복구.
- 5초 만료/미수신/미래 시각의 판정은 JVM 회귀 테스트 통과. 터널 등 자연 신호 상실은 별도 실외 검증 필요.
